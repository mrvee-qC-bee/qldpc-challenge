# [[925,173,3]] — fresh rectangular completion and boundary contractions

Author: @mrvee-qC-bee. Model: GPT-6 Astra.

## Direction & hypothesis

This is a finite improvement of the affine checkerboard construction in the
weight-4 × local-2d-single cell. The submitted code has 925 physical qubits,
173 logical qubits, maximum supplied check weight 4, one layer, unit minimum
site spacing and interaction radius √2. Its normalized geometric score is

`g = 4kd²/(nρ²r⁴) = 9×173/925 = 1.6832432432`.

That is 0.7988686% above the previous [[927,172,3]] candidate in
[PR #2591](https://github.com/unitaryfoundation/qldpc-challenge/pull/2591): two
fewer physical qubits and one more logical qubit. It is 2.7561282% above the
[[945,172,3]] reference on the audited board. The old 927-qubit input is retained
in [the prior-source artifact](../research/astra_round2_geometry/prior-927-172-3.json)
for the negative experiments below.

Credit for the affine mod-5 hole grammar belongs to @mathysrennela. Credit for
the rectangular completion algorithm belongs to @vprusso, as documented in the
[pinned 945-qubit source note](https://github.com/unitaryfoundation/qldpc-challenge/blob/ac8a779bc40524d56a6afdd2133eabd931c99c1f/notes/945-172-3.md).
This submission changes the completion parameters and performs a new finite
contraction search. It is not a claim of a new code family; literature novelty
remains unverified.

## What was searched

An algebraic census tried 1,600 fresh completions: eight rectangles, all 25
hole-phase pairs, and eight fixed completion orders. Of these, 1,156 had
complete sector coverage and commuting checks. These algebraic conditions
were not treated as distance evidence. Four selected completions were
packaged and received exact local distance-three checks.

The winning completion uses a 29×34 rectangle, phases `px=pz=0`, and order 4.
Even faces omit the X check when `x+3y=0 (mod 5)`; odd faces omit the Z check
when `x+2y=0 (mod 5)`. Boundary pins use the original completion algorithm
with NumPy PCG64 seed 924995104. This gives [[986,173,3]]. Its stabilizer group
splits into a 976-qubit encoding block and five two-qubit blocks with k=0.
Rank additivity verifies that discarding those five blocks preserves all
logical qubits; the projected core received its own exact distance check.

The winning contraction lineage then has two stages. Seed 6102901 produced
25 packaged proposals and two accepted moves, reaching 974 qubits. Seed
6103101 produced 259 proposals and 42 accepted moves. The second stage
prioritized qubits nearest the rectangle boundary after shuffling candidates.
Each pivot had qubit degree one on its Pauli side or supplied check weight two.
Pivot elimination and the existing stabilizer cleanup routine removed 51
qubits across the 44 accepted moves, giving 925. The final stabilizer group is
one connected block; final projection removes no further qubits.

Every proposal whose kit witness bound remained at least three was sent to the
unchanged SAT certifier. A move was accepted only when both Pauli sides were
UNSAT at weight at most two. All other proposals and counterexamples remain
in the [compact search archive](../research/astra_round2_geometry/search-evidence.json).
The [completion census](../research/astra_round2_geometry/completion-census.json)
records the algebraic sweep separately.

## Evidence trail

The [submission](../codes/925-173-3.json) contains weight-three logical witnesses
on both sides. Final ranks are 377 and 375, so `925−377−375=173`.
The final packaging pass used one unchanged NumPy kit trial per side, seeds
6103501 and 6103502. Trials on ancestors are not credited to this matrix.

The [local exact-distance receipt](../research/astra_round2_geometry/exact-distance.json)
records CryptoMiniSat UNSAT on both sides for all logical operators of weight
below three. It checked all 173 opposite logical classes with symmetry
reduction disabled. A separate
[fresh reproduction receipt](../research/astra_round2_geometry/reproduction.json)
repeats the exact arrays, coordinates, witness validation and the unchanged
SAT proof. Together with the supplied weight-three operators, these local
proofs establish d=3. The submission's distance fields remain `upper_bound`;
a server-issued exact badge is separate from this local evidence.

The unchanged [full candidate gate](../research/astra_round2_geometry/gate-verdict.json)
returned `passed: true`, with no exact or WL duplicate and `board_advancing: true`
in the weight-4 × local-2d-single CSS cell. Its seed is 1273063759. The displayed
8,000 RIS trials describe the configured time-capped target, not an independently
instrumented completion count. The
[structural report](../research/astra_round2_geometry/structural-verification.json)
records the one-layer layout, unit spacing, weight bound and encoding ranks.
The fingerprint is `fb25c5d75ff0d5f6`.

## Dead ends

The alternate 931-qubit source branch packaged 346 proposals and accepted only
one contraction, reaching [[930,169,3]]. It did not improve the target score.
A separate experiment from the prior 927-qubit code packaged 224 larger local
boundary cuts; every cut exposed a logical below weight three. Promoting
already returned local logicals to stabilizers produced another 351 packaged
codes, and every score-eligible endpoint again had distance below three.

Across the complete round, the archive reconstructs all 1,213 packaged cases
and preserves 1,282 witness-bearing document versions, including all 69 SAT
counterexamples. The 2,426 initial kit witness returns and 69 subsequent SAT
returns are retained; document versions repeat some already retained supports.
The [completed archive audit](../research/astra_round2_geometry/archive-audit.json)
reconstructed all 1,213 cases and validated all 2,564 stored witness slots,
including repeated supports in document versions. These bounded negative
searches are not impossibility claims.

## Tools

GPT-6 Astra used the repository submission kit, unchanged trusted GF(2) and
SAT routines, the native GF(2) accelerator, and the existing stabilizer cleanup.
The census took about 132 seconds; the winning first and boundary-prioritized
contraction stages took about 61 and 589 seconds. Other experiments ran in
parallel. No GPU was used. The trusted verifier was not modified.

## Reproduction

The [frozen constructor](../research/astra_round2_geometry/rectangle_constructor.py)
preserves the original rectangular completion implementation and its attribution.
The [recipe](../research/astra_round2_geometry/recipe.json) selects the final case
from the compact archive. From the repository root:

```sh
uv run --frozen python research/astra_round2_geometry/reproduce.py \
  --candidate codes/925-173-3.json --certify
```

The default replay follows only the final lineage. It checks the exact ordered
check matrices and coordinates, encoding ranks, both stored final witnesses,
structural verification and, with `--certify`, a fresh trusted distance proof.
The printed fingerprint must be `fb25c5d75ff0d5f6`.

To reconstruct every exploratory case and validate every archived witness:

```sh
uv run --frozen python research/astra_round2_geometry/reproduce.py \
  --candidate codes/925-173-3.json --audit-evidence
```

The complete archive audit is separate because it is more expensive; it does
not rerun a board scan or 1,213 distance searches.
