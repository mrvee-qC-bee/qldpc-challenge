# [[927,172,3]] — boundary-contracted affine checkerboard

## Direction & hypothesis

This connected CSS code advances the single-layer, weight-4 board and improves
the D=2 geometric headline from the public [[945,172,3]] score
1.638095238 to **1.669902913**, a **1.9417%** gain. It retains
172 logical qubits, unit spacing, one layer, and maximum check diameter sqrt(2),
while removing 18 physical qubits. The quoted comparison uses main at
ac8a779bc40524d56a6afdd2133eabd931c99c1f, with 1,768 entries.

The affine checkerboard grammar is due to @mathysrennela and the starting
rectangular completion and contraction construction to @vprusso. See
[the source note](https://github.com/unitaryfoundation/qldpc-challenge/blob/ac8a779bc40524d56a6afdd2133eabd931c99c1f/notes/945-172-3.md). This work extends that construction;
literature-wide novelty is unverified. No circuit-performance claim is made.

## What was searched

The [search](../research/astra_geometric/search.py) starts with the public [[945,172,3]] check matrices.
It proposes contracting a qubit with one incident check of the selected Pauli
type, or contracting through a weight-2 pivot. Same-type rows containing that
qubit are XORed with the pivot, then the pivot and qubit are removed. The
repository's existing cleanup removes fixed qubits. Each proposal must retain
k=172, maximum check weight 4, and check diameter at most sqrt(2).

Random proposal order used NumPy PCG64 seed 6100101. The run packaged
600 distinct structurally eligible proposals; 15 were
accepted. Each package received one existing NumPy witness-search trial per
side, depth 10, at seeds 6100101+100*proposal and the following integer.
Every proposal initially showing d>=3 was tested by the unchanged SAT
certifier at weight bound 2. Only two-sided UNSAT was accepted.

This is a bounded greedy search, not an exhaustive optimality claim. A rejected
move is not revisited after later changes. The [evidence](../research/astra_geometric/search-evidence.json)
records every tested matrix's reconstruction moves, initial witnesses, seeds,
check hash, and SAT result or counterexample.

For the final matrix, [the official candidate gate](../research/astra_geometric/gate-verdict.json) returns

The [fresh exact SAT run](../research/astra_geometric/exact-distance.json) spans all 172 logical classes
and reports UNSAT on both sides at weight <=2; the saved X and Z witnesses
each have weight 3. Together these prove d=3 locally.

The [structural report](../research/astra_geometric/structural-verification.json) independently recomputes
commutation, n, k, weight, layout, and one irreducible stabilizer block.
The submission retains confidence:upper_bound until a maintainer creates the
official exact-distance certificate. This local proof is separate from that
server-side badge. Maintainer certification is requested with the reproducible local SAT result.

The first standard generated circuit schedule has 33,954 X-memory and 34,085 Z-memory error mechanisms at three rounds, above the current 25,000-mechanism circuit cap. This submission therefore includes the code tier only. The [circuit preflight](../research/astra_geometric/circuit-preflight.json) records that limited experiment; other schedules were not exhausted.

## Reproduction

The [recipe](../research/astra_geometric/recipe.json) lists each move in the original base-qubit numbering,
retained indices, the base-file hash, and final hashes. The [metadata bridge](../research/astra_geometric/author-metadata.json) records the raw-file hash changes from author confirmation and publication references; checks, witnesses and layout remain identical. The portable
[reproducer](../research/astra_geometric/reproduce.py) rebuilds exactly those checks and coordinates.
From the repository root, run:

```
uv run --frozen --extra research python research/astra_geometric/reproduce.py --candidate codes/927-172-3.json --certify
```

This repeats the matrix reconstruction, structural verification and local exact SAT proof. The constructor
imports the unchanged cleanup from research/local2d/boundary_engine.py.
