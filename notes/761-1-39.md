# [[761,1,39]] — reproduction of the published cyclic toric family

## Direction & hypothesis

This submission fills a gap on the unrestricted, weight-4 **stabilizer** board.
It reproduces the family of Alexey A. Kovalev, Ilya Dumer, and Leonid P. Pryadko,
*Design of additive quantum codes via the code-word-stabilized framework*,
Physical Review A 84, 062319 (2011), Example 11
([published paper](https://doi.org/10.1103/PhysRevA.84.062319),
[preprint](https://arxiv.org/abs/1108.5490)). The construction and parameters
are known; the JSON declares `known_parameters`.

At base revision ac8a779bc40524d56a6afdd2133eabd931c99c1f, the largest
headline score in this cell was 49/25 = 1.96 for
[the 25-qubit entry](25-1-7.md). This larger-blocklength Pareto point has
kd²/n = 1521/761 = **1.998685940**, a 1.9738% headline increase.
The score uses the submitted upper-bound distance. No geometric layout or
circuit-performance claim accompanies this entry.

## What was searched

This was a deterministic literature reconstruction, not a random code search.
The smaller family member [[41,1,9]] was used as a construction calibration;
the submitted member sets t = 19, n = t² + (t+1)² = 761 and d = 2t+1 = 39.
For i modulo n, generator i has X support {i+19,i+20} and Z support {i,i+39}.
Each generator has Pauli weight 4. The affine permutation
q ↦ 38q+40 modulo 761 maps every generator to a cyclic shift of the paper's
seed with X support {1,39} and Z support {0,40}.

The explicit logical has X support {19} and Z support {0,...,38}, hence Pauli
weight 39. The overlap at qubit 19 is Y and counts once. Its commutation and
nontriviality are independently checked by the repository's trusted verifier.

extended tier's d ≤ 40 limit. Scaling this family further therefore cannot

## Reproduction

From the repository root:

```sh
uv run python research/astra_cyclic_761/reproduce.py --candidate codes/761-1-39.json
```

The [reproducer](../research/astra_cyclic_761/reproduce.py) rebuilds every
generator and the supplied witness, checks the affine correspondence to the
published family, and calls the trusted structural verifier. It also checks
the retained gate's fingerprint, signature and validator hash. It performs
no new distance search. After promotion, rerun the trusted structural and
refutation verifier on this entry with:

```sh
uv run python verify/qldpc_verify.py codes/761-1-39.json
```
